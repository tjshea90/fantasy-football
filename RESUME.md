# RESUME — start here only if the automatic briefing did not appear

**This file is no longer the resume card.** `CHECKPOINT.md` is, and it is
regenerated by `tools/ckpt.sh` on every checkpoint so it cannot go stale.
This file used to carry a v1.8-era "unzip the bundle" procedure from when the
project moved between chats as a zip; GitHub replaced that, and the old
instructions here were wrong for seven versions before being cut.

## Resuming, in full

Open <https://github.com/tjshea90/fantasy-football> in a Claude Code session
on any of the three Claude accounts and say **"continue"**. That is the whole
procedure. The `SessionStart` hook in `.claude/settings.json` runs
`tools/resume.sh`, which pulls the latest commits and prints `CHECKPOINT.md`,
`TASKS.md` and the project's standing rules into the session automatically.

Nothing is attached, uploaded, or re-explained, and it does not matter which
account was used last.

If that briefing did not appear, the hook did not fire — run it by hand:

```bash
bash tools/resume.sh
```

and mention it, because the automatic checkpointing described in `CLAUDE.md`
is probably not running either.
